## 실행 환경과 준비

- macOS 26.5.2, arm64.
- Python 3.13.16으로 `backends/.venv`를 새로 생성했다. 시스템 기본 Python은 사용하지 않았다.
- `.venv/bin/python -m pip install -r requirements.txt`로 의존성을 설치했다. `requirements.txt`는 변경하지 않았다.
- [실제 설치된 Python 버전 목록](2026-11-11-python-environment.txt)을 저장했다. 이는 이번 환경의 기록이며 운영용 lockfile을 새로 도입한 것이 아니다. OS별 패키지가 있어 다른 플랫폼에 그대로 적용되는 것은 보장하지 않는다.
- 주요 패키지: pytest 9.2.0, pytest-asyncio 1.4.1.post1, FastAPI 0.162.4, Pydantic 2.14.3, LangGraph 1.2.20, PyMuPDF 2.1.
- Node.js 26.11.1, npm 11.20.0. 기존 `package-lock.json`으로 `npm ci --no-audit --no-fund`를 실행했다. 잠금 파일은 변경하지 않았다.
- 프론트 빌드 도구 Vite 7.1.6. 1,973개 모듈을 처리했고 Vite 빌드 시간은 2.91초였다(TypeScript 검사 포함 전체 시간은 별도 측정하지 않음).
- 저장소 CI는 Ubuntu, Python 3.13, Node.js 20을 사용한다. 이번 검사는 로컬 macOS/Node 26 결과이며 CI 환경 재실행은 아니다.
- 처음 패키지 다운로드는 sandbox DNS 제한으로 실패했다. 승인된 네트워크 접근으로 재시도해 설치를 완료했다. 제품 코드 실패와 구분한다.

## 경고

### 백엔드

- pytest 요약의 경고 4개: SWIG 타입의 `__module__` 관련 DeprecationWarning 3개, `fitz` import의 FutureWarning 1개.
- 추가로 시작 시 `asyncio_default_fixture_loop_scope`가 설정되지 않았다는 pytest-asyncio 경고가 출력됐다. 위 4개 요약과 별도로 기록한다.
- 테스트 실패는 아니며 이번 기준선 작업에서는 설정·import를 바꾸지 않았다.

### 프론트

- `baseline-browser-mapping`과 Browserslist의 `caniuse-lite` 데이터가 오래됐다는 경고. 빌드는 성공했다. 기준선을 유지하려고 업데이트하지 않았다.
- npm 설치 시 `esbuild`, `fsevents`의 install script가 allowScripts에 포함되지 않았다는 경고가 있었다. 별도 승인 설정은 변경하지 않았으며 이후 실제 빌드는 성공했다.
